AIDD 文献雷达 v1.0 使用说明

一、运行环境
64 位 Windows 10 或 Windows 11。

二、安装与启动
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“AIDD文献雷达-v1.0.exe”。
3. 首次运行会在程序旁创建 data 文件夹，用于保存论文库、翻译、收藏和阅读状态。
4. Windows SmartScreen 如显示“未知发布者”，请确认安装包来自官方发布页并核对 SHA-256 后再运行。

三、获取论文
1. 点击“获取论文”。
2. 选择获取最新或按范围获取。
3. 分别选择期刊、会议和预印本来源。
4. 确认日期或会议年份后开始。
5. 完整摘要筛选会更加耗时，适合需要逐篇补全摘要时使用。

四、阅读与管理
主界面支持搜索、分类与来源筛选、收藏、已读/未读、重新翻译、打开原文和 CSV 导出。移动或升级软件时，请保留 data 文件夹。
